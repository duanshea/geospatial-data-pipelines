# geospatial-data-pipelines

## Overview
Small, practical geospatial data pipeline exercises (ingest → transform → analyze → export).

## Goals
- Build reproducible workflows
- Practice geospatial ETL patterns
- Keep short notes on design choices

## Structure
- `data/` — inputs (or links to sources)
- `notebooks/` — exploration
- `src/` — reusable code
- `outputs/` — generated artifacts
- `docs/` — write-ups
